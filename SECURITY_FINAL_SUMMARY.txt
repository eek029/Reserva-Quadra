🔧 AÇÕES IMEDIATAS (HOJE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CORRIGIR AUTENTICAÇÃO EM /api/reservas/presencial
   ├─ Problema: Usa header customizado 'requester-id' sem validação
   ├─ Risco: Qualquer pessoa pode criar reservas em nome de outros
   ├─ Tempo: 2-4 horas
   ├─ Arquivo: src/app/api/reservas/presencial/route.ts
   └─ Fix: Usar JWT do Authorization header

2. ATUALIZAR NEXT.JS PARA 15.0+
   ├─ Problema: SSRF e Cache Poisoning em Next.js 14.1.0
   ├─ Risco: Requisições arbitrárias do servidor
   ├─ Tempo: 1-2 horas
   ├─ Comando: npm update next@latest
   └─ Verificar: npm list next

3. EXECUTAR npm audit fix
   ├─ Problema: 10 vulnerabilidades em dependências
   ├─ Risco: DoS, RCE, ReDoS
   ├─ Tempo: 30 minutos
   ├─ Comando: npm audit fix
   └─ Verificar: npm audit

4. ADICIONAR SECURITY HEADERS
   ├─ Problema: Falta de headers de segurança
   ├─ Risco: XSS, Clickjacking, MIME sniffing
   ├─ Tempo: 30 minutos
   ├─ Arquivo: next.config.mjs
   └─ Headers: X-Content-Type-Options, X-Frame-Options, etc.
