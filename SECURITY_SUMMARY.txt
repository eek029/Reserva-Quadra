🔴 VULNERABILIDADES CRÍTICAS (AÇÃO IMEDIATA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  SSRF em Next.js Server Actions
    Arquivo: package.json (Next.js 14.1.0)
    CVSS: 9.1 (Crítica)
    Impacto: Requisições arbitrárias do servidor
    Fix: npm update next@latest
    
2️⃣  Cache Poisoning em Next.js
    Arquivo: package.json (Next.js 14.1.0)
    CVSS: 7.5 (Crítica)
    Impacto: Respostas cacheadas servidas a usuários não autorizados
    Fix: npm update next@latest
    
3️⃣  Autenticação Fraca em /api/reservas/presencial
    Arquivo: src/app/api/reservas/presencial/route.ts:10-17
    CVSS: 9.0 (Crítica)
    Impacto: Broken Access Control - criar reservas em nome de outros
    Fix: Usar JWT do Authorization header, não header customizado
    
    ❌ VULNERÁVEL:
    const requesterId = request.headers.get('requester-id');
    
    ✅ CORRETO:
    const { data: { user } } = await supabase.auth.getUser(token);
    const requesterId = user.id;
